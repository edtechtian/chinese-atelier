# Public source release — 12 November 2026

The exact publication copy passed all 41 Python unittest tests, covering the course API, 100-step progression, review scheduling, teacher workflow, persistence, visual answer keys and frontend rendering. Adaptation and visual validators also passed. Tests use isolated temporary records.

Original PPTX files and full archive assets are deliberately omitted. Runtime visual practice uses the included optimized derivatives; its validator accepts these only when publication-assets.json explicitly declares that publication policy. The full source-archive validator still requires original files and must not be described as passing for this public copy.

One optimized greeting illustration was added during packaging because its original was not part of the public archive. Private originals and actual student records were untouched. Machine-local metadata was redacted in publication copies only; stable lesson and slide IDs and source wording are retained.

No student state, teacher key, credential files, backups, private QA screenshots or unrelated debate application are included. A fresh clone generates its own empty records and teacher key.

This is a public source-code release. The Python app runs locally; this release does not deploy a shared hosted service.
